# Trivia Game

A simple trivia game built with Python and Tkinter.

Each question has four options. Pick one: a correct answer shows a positive message, and a wrong one shows a different message along with the right answer.

## Features

- Five multiple-choice questions
- Correct and wrong answers are highlighted in green and red
- A running score, plus a final result screen
- **Restart** button to start over at any time

## Run

Requires Python 3 (Tkinter is included with the standard Windows/macOS installers).

```
python trivia_game.py
```
